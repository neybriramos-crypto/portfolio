# Portafolio Personal — Neymar Brito

Portafolio web personal desarrollado con HTML, Tailwind CSS y DaisyUI para presentar proyectos, habilidades y datos de contacto de una desarrolladora Full Stack.

## Descripción

Este proyecto consiste en una landing page moderna y responsive para mostrar:

- Biografía profesional
- Proyectos destacados
- Stack tecnológico
- Información de contacto
- Tema claro/oscuro
- Animaciones y diseño visual atractivo

La interfaz está pensada para destacar trabajo técnico, creatividad y experiencia en desarrollo web.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- DaisyUI
- Animate.css
- AOS (Animate On Scroll)
- Font Awesome
- EmailJS para el formulario de contacto

## Características

- Diseño responsive y adaptable a dispositivos móviles
- Barra de navegación fija con enlaces internos
- Presentación principal con texto tipado dinámico
- Sección de proyectos con cards visuales
- Indicadores de habilidades por tecnologías
- Cambio de tema claro/oscuro
- Formulario de contacto funcional con EmailJS
- Animaciones suaves para una mejor experiencia visual

## Requisitos

Para visualizar el proyecto localmente necesitas:

- Un navegador web moderno
- Conexión a internet para cargar CDN de Tailwind, DaisyUI, AOS y Font Awesome

## Cómo ejecutarlo

1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta el archivo `index.html` en tu navegador.

Alternativamente, si prefieres usar un servidor local:

```bash
python -m http.server 8000
```

Luego entra en:

```text
http://localhost:8000
```

## Personalización

Puedes modificar fácilmente la información del portafolio en `index.html`:

- Nombre y título profesional
- Descripción de proyectos
- Tecnologías y skills
- Enlaces de contacto
- Mensaje del formulario
- Colores principales del tema
